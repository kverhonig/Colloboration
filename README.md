# Smart Grocery – Backup

## Dateien

- `index.html` – Aufbau der Web-App
- `style.css` – Design und responsive Darstellung
- `app.js` – gesamte Interaktion und Berechnung
- `products.json` – Produktdaten
- `PROJEKTPLAN.md` – Projektbeschreibung, Anforderungen, Algorithmus und Tests

## Lokal testen

Die Website kann auch direkt per Doppelklick auf `index.html` geöffnet werden. Falls der Browser den Zugriff auf `products.json` blockiert, verwendet die App automatisch eingebaute Fallback-Produktdaten. Für die endgültige Web-Version (z. B. Netlify) wird die `products.json` normal geladen.

Eine einfache Möglichkeit mit VS Code ist z. B. die Erweiterung „Live Server“. Alternativ kann der komplette Ordner direkt auf Netlify hochgeladen werden.

## Wichtig

Die Preise in `products.json` sind Beispieldaten für das Projekt und sollten vor der Abgabe als Projektdaten gekennzeichnet bzw. nach den Vorgaben des Teams angepasst werden.

## Projektidee

Die Web-App entwickelt den Algorithmus aus Exercise 3 weiter: Statt einer Java-Konsolenanwendung wird der Preisvergleich als interaktive Website umgesetzt.
